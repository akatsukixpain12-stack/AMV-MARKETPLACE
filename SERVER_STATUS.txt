========================================
API ENDPOINTS AVAILABLE
========================================

AUTH:
POST /api/auth/register - Register new user
POST /api/auth/login - Login
POST /api/auth/google - Google OAuth
GET  /api/auth/me - Get current user

GIGS:
GET  /api/gigs - List all gigs
GET  /api/gigs/:id - Get gig details
POST /api/gigs - Create gig (auth required)
PUT  /api/gigs/:id - Update gig (auth required)

ORDERS:
POST /api/orders/create - Create order
GET  /api/orders/my-orders - Get user orders
POST /api/orders/:id/complete - Complete order
POST /api/orders/:id/deliver - Deliver order

PAYMENTS:
POST /api/payment/razorpay/create - Create Razorpay payment
POST /api/payment/razorpay/verify - Verify payment
POST /api/payment/upi/create - Create UPI payment

WITHDRAWALS:
POST /api/withdrawal/request - Request withdrawal
GET  /api/withdrawal/history - Get withdrawal history

REVIEWS:
POST /api/reviews - Create review

SEARCH:
GET  /api/search - Advanced search

AI TOOLS:
POST /api/ai/remove-background - Background removal
POST /api/ai/detect-plagiarism - Plagiarism detection
