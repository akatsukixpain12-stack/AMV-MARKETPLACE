========================================
TROUBLESHOOTING
========================================

If signup doesn't work:
1. Check browser console (F12)
2. Check if backend is running (http://localhost:5000)
3. Try different username/email
4. Check password matches

If pages don't load:
1. Refresh the page
2. Clear browser cache
3. Check both servers are running
4. Look at terminal for errors

If AI tools don't work:
1. Try smaller image (< 5MB)
2. Use PNG or JPG format
3. Check browser console for errors
